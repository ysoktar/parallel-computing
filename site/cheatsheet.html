3. Tiled matmul: W×W, T×T, W % T = 0

__shared__ float Mds[T][T], Nds[T][T];
int row=blockIdx.y*T+ty, col=blockIdx.x*T+tx;
float sum=0;
for (int m=0; m<W/T; ++m) {
  Mds[ty][tx] = M[row*W + m*T + tx];
  Nds[ty][tx] = N[(m*T + ty)*W + col];
  __syncthreads();                // tile ready
  for (int k=0;k<T;++k) sum+=Mds[ty][k]*Nds[k][tx];
  __syncthreads();                // tile may be overwritten
}
P[row*W+col]=sum;

W=matris genişliği, T=karo kenarı (bu örnekte blockDim.x=blockDim.y=T); tx=threadIdx.x, ty=threadIdx.y; m=phase (yüklenen karo numarası, 0'dan başlar), k=karo içi çarpım indeksi (0..T-1). Mds/Nds=shared karolar, sum=biriken sonuç. İlk bariyer yüklemeyi, ikinci yeniden kullanımı korur.

8×32 tiled örneği: Mds[32][8], Nds[8][8]; Nds'yi yalnız ty<8 yükler, iki bariyer koşul dışındadır.

5. __syncthreads() kuralları

// wrong: divergent barrier
if (tid<16) { s[tid]=v; __syncthreads(); }
// correct:
if (tid<16) s[tid]=v;
__syncthreads();
// load → sync → use → sync → next load

Blok bariyeridir; tüm katılan thread'ler erişmeli. Shared yazma→başka thread okuma için sync; erken return/ayrışan if tehlikeli.

6. Shared memory ve reverse

__shared__ float s[B]; // per-block, on-chip
int t=threadIdx.x, i=blockIdx.x*B+t;
s[t]=in[i]; __syncthreads();
out[i]=s[B-1-t]; // reverse within block
// reuse tile before loading next phase

Bariyer olmadan başka thread'in yazdığı değeri okumak race yaratabilir. Bloklar bağımsız.

7. Global bellek / coalescing / pitch

32 lanes × float(4 B) = 128 B requested
aligned a[lane] → 4×32 B segments (128 B)
a[lane+1] → 5 segments (160 B)
a[2*lane] → 8 segments (256 B)
a[1024*lane] → 32 segments (1024 B)
a[0] → 1 segment (broadcast)
byte_addr = base + (row*pitchBytes) + col*4
cudaMallocPitch(&p, &pitchBytes, W*4, H);

lane=warp içi thread sırası (0–31), float=4 B; 32 B=örnek hizalı bellek segmenti, her GPU'da cache-line boyutu demek değildir. row/col=matris koordinatları, W=sütun sayısı; pitchBytes=bayt cinsinden satır adımı, W*4'ten büyük olabilir. Gerçek işlemler cache'e bağlıdır.

8. Transpose: adresin yönü

// A and B: N×N, row-major
naive: B[col*N+row] = A[row*N+col];
read: adjacent col → contiguous
write: adjacent col → stride N
shared (T=32, block=32×32):
tile[ty][tx] = A[(by*T+ty)*N + bx*T+tx];
__syncthreads();
B[(bx*T+ty)*N + (by*T+tx)] = tile[tx][ty];

bx=blockIdx.x, by=blockIdx.y (blok koordinatları); tx=threadIdx.x, ty=threadIdx.y (blok içi thread); T=karo boyutu, N=matrisin sütun sayısı. A→B satır/sütun takas eder. Naive yazma adresi N eleman atlayabilir.

9. Sayısal sorular / CGMA

speedup = Tserial/Tparallel
efficiency = speedup/N
threads/block = bx*by*bz
warps/block = ceil(threads/block / 32)
resident blocks/SM limited by:
  threads, shared bytes, registers, max blocks
CGMA = floating-point ops / global-memory accesses
BW-limited GFLOPS ≈ BW(GB/s)*ops/byte

Eski GPU slaytlarındaki donanım sınırlarını modern GPU'ya genelleme. Sayı sorusunda verilen cihazın limitlerini kullan.

10. Bellek türleri (scope / lifetime)

register  : thread özel, SM register dosyası
local     : thread özel; spill cihaz DRAM'inde
shared    : blok ortak, SM içi hızlı bellek
L1 cache  : her SM'ye ait, donanım yönetir
L2 cache  : tüm SM'lerin ortak cache'i
global    : GPU DRAM/VRAM, tüm thread'ler

L1/shared bazı GPU'larda aynı çip içi havuzu böler
1 KiB=1024 B; float=4 B; 32 float=128 B

Kapsam ≠ fiziksel yer: local thread'e özeldir ama cihaz belleğinde olabilir; shared ile aynı değildir. Cache otomatik tutulan veri kopyasıdır, __shared__ açıkça programlanır. L1/L2 boyutları GPU modeline bağlıdır.

12. Warp, blok, gecikme gizleme

warp = 32 consecutive linear thread IDs
linearID = ty*blockDim.x + tx (2D)
block → 1 SM; blocks run independently
latency hiding: ready warp while another waits
occupancy ≠ automatically higher performance
SIMT: threads share instruction issue, can diverge

Warp kimliği blok içinde hesaplanır; blokların hangi SM'ye/ sırayla atanacağı garanti edilmez.

13. Lecture 1–3: hızlı özet

Amdahl: S=1/((1-f)+f/N); N→∞: 1/(1-f)
Gustafson: S=(1-a)+a*N   (a=parallel-time share)
Flynn: SISD / SIMD / MISD / MIMD
PCAM: Partition → Communication → Agglomeration → Mapping
patterns: task, D&C, geometric, pipeline (slowest stage)
data race: unsynchronised conflicting accesses, >=1 write
mutex: mutual exclusion/ownership ; semaphore: permits
deadlock: wait forever; livelock: moving no progress
starvation: one participant never proceeds

Amdahl: f=sabit problemin paralelleştirilebilir oranı, N=işçi sayısı, S=hızlanma. Gustafson: a=paralel yürütme süresi oranı, N=işçi sayısı. Burada N matris boyutu DEĞİL. Mutex=tek sahip; semaphore=izin sayısı; race=korunmasız eşzamanlı erişim.

3. Mutex, lock_guard ve semaphore aynı şey değil

#include <mutex>
#include <semaphore>
std::mutex m;
std::counting_semaphore<3> slots(3);
int counter=0;
void job(){
  slots.acquire(); // at most 3 jobs enter
  { std::lock_guard<std::mutex> hold(m);
    ++counter; }  // only 1 thread modifies it
  doWork();
  slots.release();
}
// Without mutex, 3 concurrent increments may race.

Fark: Semaphore aynı anda 3 işe izin verebilir; bu, counter++ için karşılıklı dışlama sağlamaz. mutex tek kilit sahibine izin verir. lock_guard kapsam sona erdiğinde mutex'i otomatik açar.

Sözel cevap: İki thread m1→m2 ve m2→m1 sırasıyla kilit beklerse deadlock olabilir. Starvation bir thread'in sürekli geride bırakılmasıdır. Bir C++ data race için belirli çıktı garanti edilmez.

6. Transpose: aynı değer, farklı lineer indeks

A is 3×5 (H=3,W=5), B is 5×3
A[row=1][col=3] => A[1*5+3] = A[8]
B[col=3][row=1] => B[3*3+1] = B[10]
__global__ void trans(float*A,float*B,int H,int W){
  int row=blockIdx.y*blockDim.y+threadIdx.y;
  int col=blockIdx.x*blockDim.x+threadIdx.x;
  if(row<H && col<W) B[col*H+row]=A[row*W+col];
}

Neden: A genişliği 5, B genişliği 3'tür. Değerin satır/sütun koordinatları yer değiştirir. Komşu x-lane'ler A'yı ardışık okuyabilir fakat B'ye yazarken H elemanlık stride ile ayrılır.

Sınav yöntemi: Önce çıktı matrisinin boyutunu yaz (W×H); sonra hedefin lineer adresini hedef matrisin yeni genişliği ile çarp.

İlgili deneme sorusunu çöz
