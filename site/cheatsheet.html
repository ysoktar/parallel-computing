3. Tiled matmul (kare T)

__shared__ float Mds[T][T], Nds[T][T]; Row = by*T + ty; Col = bx*T + tx; P = 0; for (m = 0; m < W/T; ++m) { Mds[ty][tx] = M[Row*W + m*T + tx]; // M: satır Row, sütun m*T+tx Nds[ty][tx] = N[(m*T + ty)*W + Col]; // N: satır m*T+ty, sütun Col __syncthreads(); // (1) karo dolsun (RAW) for (k = 0; k < T; ++k) P += Mds[ty][k]*Nds[k][tx]; __syncthreads(); // (2) üzerine yazılmasın (WAR) } Pd[Row*W + Col] = P; global okuma/thread: 2W → 2W/T (T kat az) ; shared/blok = 2·T²·4 B BX×BY blokta azalma = 2·BX·BY/(BX+BY) (16×8 ≈ 10,7 ; 32×8 = 12,8)

5. __syncthreads() kuralları

  • Sadece blok içi bariyer; bloklar arası yok (kernel'i böl / cooperative groups, CUDA 9+).
  • Bloktaki tüm thread'ler çalıştırmalı. if içinde ya da erken return sonrası = tanımsız (koşul herkes için aynıysa hariç).
  • Başka thread'in yazdığı shared veriyi okumadan önce şart. Aslında warp'ları senkronize eder.
  • ✗ if (tid<16){ s[tid]=..; __syncthreads(); } → ✓ if (tid<16) s[tid]=..; __syncthreads();

6. Shared memory deseni

__shared__ float s[N]; // blok başına 1 kopya, blok ömrü, on-chip 1) işbirliğiyle yükle 2) __syncthreads() 3) tekrar tekrar kullan 4) sync 5) global'e yaz reverse: s[t] = d[base+t]; sync; d[base+t] = s[B-1-t]; (sync yoksa race) "önce kopyala": global→shared→global, çıktı == girdi mi? sonra hesabı ekle
