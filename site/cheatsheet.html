Kopya kâğıdı planı

Kural: 1 adet A4, iki yüz, el yazısı, sınavdan önce kontrol ediliyor. Aşağıdaki her kutu kâğıtta yaklaşık bir bölge. Elle yazarken sıkıştırın; yazmanın kendisi de iyi bir tekrar.

Bu sayfayı yazdırıp götüremezsiniz: fotokopi ve bilgisayar çıktısı yasak. Buradakini kendi elinizle kâğıda geçirin.

Ön yüz: CUDA çekirdeği

1. İndeksler

dim3(x, y): x = sütun, y = satır blok ≤ 1024 thread, warp = 32 col = blockIdx.x*blockDim.x + threadIdx.x row = blockIdx.y*blockDim.y + threadIdx.y A[row*W + col] id(2D) = ty*bdx + tx id(3D) = tz*bdx*bdy + ty*bdx + tx warp = id/32 gid(1D) = blockIdx.x*blockDim.x + threadIdx.x grid = (W + bx - 1)/bx ; if (row < H && col < W) kapsanan = (gx*bx) sütun × (gy*by) satır dim3(8,32): warp = 4 satır × 8 sütun (ty 4w..4w+3)

2. Host iskeleti

float *d; cudaMalloc((void**)&d, bytes); cudaMemcpy(dst, src, bytes, cudaMemcpyHostToDevice); // senkron k<<<grid, block>>>(...); // asenkron → cudaDeviceSynchronize() cudaMemcpy(h, d, bytes, cudaMemcpyDeviceToHost); cudaFree(d); __global__: device'ta, host çağırır | __device__: d/d | __host__: h/h

3. Tiled matmul (ezber)

__shared__ float Mds[T][T], Nds[T][T]; Row = by*T + ty; Col = bx*T + tx; P = 0; for (m = 0; m < W/T; ++m) { Mds[ty][tx] = M[Row*W + m*T + tx]; Nds[ty][tx] = N[(m*T + ty)*W + Col]; __syncthreads(); // (1) dolsun (RAW) for (k = 0; k < T; ++k) P += Mds[ty][k]*Nds[k][tx]; __syncthreads(); // (2) üzerine yazılmasın (WAR) } Pd[Row*W + Col] = P; global okuma/thread: 2W → 2W/T ; azalma T ; BX×BY: 2·BX·BY/(BX+BY) 8×32 blok: Mds[32][8] (herkes), Nds[8][8] (ty<8), sync if dışında

4. __syncthreads()

  • Sadece blok içi bariyer; bloklar arası yok (cooperative groups, CUDA 9+).
  • Bloktaki tüm thread'ler çalıştırmalı; if içinde / erken return sonrası = tanımsız (koşul herkes için aynıysa hariç).
  • Başka thread'in yazdığı shared veriyi okumadan önce şart.

5. Coalescing

transaction: 32/64/128 B, boyutuna hizalı; cudaMalloc ≥ 256 B hizalı kelime 1/2/4/8/16 B, doğal hizalı; struct __align__(8/16) rastgele 4B: 32×32 = 1024 B ; ardışık: 128 B → 8 kat a[i] 4 seg ✓ | a[i+1] 5 seg | a[2i] 8 seg (%50) | a[i*W] 32 seg ✗ | a[0] 1 seg 2D: blok genişliği ve dizi genişliği 32'nin katı → cudaMallocPitch row = (float*)((char*)p + r*pitch)

6. Transpose

naive: out[x*W + y] = in[y*W + x] okuma ✓ yazma ✗ (stride W) shared: tile[ty][tx] = in[y*W + x]; sync; x = by*T + tx; y = bx*T + ty; out[y*W + x] = tile[tx][ty] NVIDIA: T=32, blok 32×8, thread başına 4 eleman (j += 8) padding [T][T+1] = bank conflict (FİNALDE)

Arka yüz: sayılar, bellek, derleme, L1–L3

10. L1–L3 hızlı
