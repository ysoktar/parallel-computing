Index and coalescing lab

Practice for the exam's "which index points where, which locations does this code touch" questions. The tools run in the browser; they do not simulate CUDA, they only compute the index arithmetic and the memory segments.

Thread → data mapping

Change the grid and block sizes and click a cell. The red cell is the selected thread; the coloured region is its block, the dark colour its warp. Start with <<<(3,3),(8,32)>>>, then set blockDim.x to 32 and watch how the shape of the warps changes.

  • blockDim.x = 8: a warp is 4 rows × 8 columns. The 8 floats of a row = 32 B; the warp touches 4 separate places in memory.
  • blockDim.x = 32: a warp is exactly one piece of a row (32 consecutive floats = 128 B). That is the reason for the slide rule "the block width should be a multiple of 32".
  • With values that do not divide 32, such as blockDim.x = 12, warps start in the middle of a row.

Actually running CUDA code

Every code block on the site has a ▶ Run button. Since a browser cannot run a compiler, a small helper program on your computer compiles and runs the code: C/C++ with g++/clang++ on the CPU, CUDA with nvcc on the GPU.

  1. Download runner.py (only Python 3 is needed).
  2. In a terminal: python3 runner.py (Windows: py runner.py). The buttons work while the window is open.
  3. ✎ Edit · parameters: edit the block's full program, write compiler flags (e.g. -O3, -arch=sm_86, -gencode …, --ptxas-options=-v) and program arguments (e.g. the matrix size).

The runner listens only on 127.0.0.1 and accepts requests only from this site. Without a compiler on your computer: Google Colab (T4 GPU; %%writefile k.cu and !nvcc k.cu -o k && ./k), or godbolt.org to see the compiled output (PTX/SASS).

#include 
__global__ void who(int width) {
    int col = blockIdx.x * blockDim.x + threadIdx.x;
    int row = blockIdx.y * blockDim.y + threadIdx.y;
    int id  = threadIdx.y * blockDim.x + threadIdx.x;
    if (blockIdx.x == 2 && blockIdx.y == 1 && threadIdx.x == 5 && threadIdx.y == 10)
        printf("row=%d col=%d warp=%d P[%d]\n", row, col, id / 32, row * width + col);
}
int main() {
    who<<>>(24);
    cudaDeviceSynchronize();   // kernels are asynchronous: wait to see the output
}
