Front: the CUDA core

1. Indices

dim3(x, y): x = column, y = row block ≤ 1024 threads, warp = 32 col = blockIdx.x*blockDim.x + threadIdx.x row = blockIdx.y*blockDim.y + threadIdx.y A[row*W + col] id(2D) = ty*bdx + tx id(3D) = tz*bdx*bdy + ty*bdx + tx warp = id/32 gid(1D) = blockIdx.x*blockDim.x + threadIdx.x grid = (W + bx - 1)/bx ; if (row < H && col < W) covered = (gx*bx) columns × (gy*by) rows dim3(8,32): warp = 4 rows × 8 columns (ty 4w..4w+3)

2. Host skeleton

float *d; cudaMalloc((void**)&d, bytes); cudaMemcpy(dst, src, bytes, cudaMemcpyHostToDevice); // synchronous k<<<grid, block>>>(...); // asynchronous → cudaDeviceSynchronize() cudaMemcpy(h, d, bytes, cudaMemcpyDeviceToHost); cudaFree(d); __global__: on device, called by host | __device__: d/d | __host__: h/h

3. Tiled matmul (memorise)

__shared__ float Mds[T][T], Nds[T][T]; Row = by*T + ty; Col = bx*T + tx; P = 0; for (m = 0; m < W/T; ++m) { Mds[ty][tx] = M[Row*W + m*T + tx]; Nds[ty][tx] = N[(m*T + ty)*W + Col]; __syncthreads(); // (1) filled (RAW) for (k = 0; k < T; ++k) P += Mds[ty][k]*Nds[k][tx]; __syncthreads(); // (2) not overwritten (WAR) } Pd[Row*W + Col] = P; global reads/thread: 2W → 2W/T ; reduction T ; BX×BY: 2·BX·BY/(BX+BY) 8×32 block: Mds[32][8] (everyone), Nds[8][8] (ty<8), sync outside the if

4. __syncthreads()

  • Barrier within a block only; none across blocks (cooperative groups, CUDA 9+).
  • All threads of the block must execute it; inside an if / after an early return = undefined (unless the condition is the same for everyone).
  • Required before reading shared data written by another thread.

5. Coalescing

transaction: 32/64/128 B, aligned to its size; cudaMalloc ≥ 256 B aligned word 1/2/4/8/16 B, naturally aligned; struct __align__(8/16) random 4B: 32×32 = 1024 B ; consecutive: 128 B → 8 times a[i] 4 seg ✓ | a[i+1] 5 seg | a[2i] 8 seg (50%) | a[i*W] 32 seg ✗ | a[0] 1 seg 2D: block width and array width multiples of 32 → cudaMallocPitch row = (float*)((char*)p + r*pitch)

6. Transpose

naive: out[x*W + y] = in[y*W + x] read ✓ write ✗ (stride W) shared: tile[ty][tx] = in[y*W + x]; sync; x = by*T + tx; y = bx*T + ty; out[y*W + x] = tile[tx][ty] NVIDIA: T=32, block 32×8, 4 elements per thread (j += 8) padding [T][T+1] = bank conflicts (ON THE FINAL)
