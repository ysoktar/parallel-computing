1. Indices + warp shape

dim3(x, y): x = column, y = row block ≤ 1024 threads, warp = 32 col = blockIdx.x*blockDim.x + threadIdx.x row = blockIdx.y*blockDim.y + threadIdx.y A[row*W + col] id(2D) = ty*bdx + tx id(3D) = tz*bdx*bdy + ty*bdx + tx warp = id/32 gid(1D) = blockIdx.x*blockDim.x + threadIdx.x (block b, thread t: b*M + t) grid = (W + bx − 1)/bx ; if (row < H && col < W) covered = (gx*bx) columns × (gy*by) rows dim3(8,32): warp w = ty 4w..4w+3 (4 rows × 8 cols) dim3(32,8): warp = 1 row

3. Tiled matmul (square T)

__shared__ float Mds[T][T], Nds[T][T]; Row = by*T + ty; Col = bx*T + tx; P = 0; for (m = 0; m < W/T; ++m) { Mds[ty][tx] = M[Row*W + m*T + tx]; // M: row Row, column m*T+tx Nds[ty][tx] = N[(m*T + ty)*W + Col]; // N: row m*T+ty, column Col __syncthreads(); // (1) tile filled (RAW) for (k = 0; k < T; ++k) P += Mds[ty][k]*Nds[k][tx]; __syncthreads(); // (2) not overwritten (WAR) } Pd[Row*W + Col] = P; global reads/thread: 2W → 2W/T (T times fewer) ; shared/block = 2·T²·4 B reduction for a BX×BY block = 2·BX·BY/(BX+BY) (16×8 ≈ 10.7 ; 32×8 = 12.8)

4. <<<(3,3),(8,32)>>> solution + 8×32 tiled

5. __syncthreads() rules

  • Barrier within a block only; none across blocks (split the kernel / cooperative groups, CUDA 9+).
  • All threads of the block must execute it. Inside an if or after an early return = undefined (unless the condition is the same for everyone).
  • Required before reading shared data written by another thread. It actually synchronises warps.
  • ✗ if (tid<16){ s[tid]=..; __syncthreads(); } → ✓ if (tid<16) s[tid]=..; __syncthreads();

6. Shared memory pattern

__shared__ float s[N]; // one copy per block, block lifetime, on-chip 1) load cooperatively 2) __syncthreads() 3) use repeatedly 4) sync 5) write to global reverse: s[t] = d[base+t]; sync; d[base+t] = s[B-1-t]; (race without sync) "copy first": global→shared→global, output == input? then add the computation

8. Transpose

T = 32, block dim3(32, 8), grid (N/32, N/32), 4 elements per thread (j += 8) copy: o[(y+j)*W + x] = i[(y+j)*W + x] ✓ ✓ (ceiling) naive: o[x*W + (y+j)] = i[(y+j)*W + x] read ✓ write ✗ (stride W) shared: tile[ty+j][tx] = i[(y+j)*W + x]; __syncthreads(); x = by*T + tx; y = bx*T + ty; // blocks swap places o[(y+j)*W + x] = tile[tx][ty+j]; ✓ ✓ GB/s (M2050): copy 105, naive 19, coalesced 51
