İndeks ve coalescing laboratuvarı

Sınavdaki "hangi indeks nereyi gösteriyor, bu kod nerelere dokunuyor" sorularının pratiği. Araçlar tarayıcıda çalışır; CUDA'yı simüle etmez, sadece indeks aritmetiğini ve bellek segmentlerini hesaplar.

Thread → veri eşlemesi

Grid ve blok boyutlarını değiştirin, bir hücreye tıklayın. Kırmızı hücre seçili thread; renkli bölge onun bloğu, koyu renk onun warp'ı. Önce <<<(3,3),(8,32)>>> ile başlayın, sonra blockDim.x'i 32 yapıp warp'ların şeklinin nasıl değiştiğine bakın.

  • blockDim.x = 8: bir warp 4 satır × 8 sütun. Bir satırdaki 8 float = 32 B; warp bellekte 4 ayrı yere dokunur.
  • blockDim.x = 32: bir warp tam bir satır parçası (32 ardışık float = 128 B). Slayttaki "blok genişliği 32'nin katı olsun" kuralının nedeni bu.
  • blockDim.x = 12 gibi 32'yi bölmeyen değerlerde warp'lar satır ortasında başlar.

Warp erişimi ve coalescing

Bir warp'ın 32 thread'inin adreslerini ve dokunduğu segmentleri gösterir. Ayrıntılı açıklama: Coalescing sayfası.

Tiled matris çarpımı

Hangi blok hangi karoyu hesaplar, faz m'de shared memory'ye hangi elemanlar gelir, her thread hangi elemanı yükler. Kod: L5.

CUDA kodunu gerçekten çalıştırmak

Sitedeki her kod bloğunun altında ▶ Çalıştır düğmesi var. Tarayıcı derleyici çalıştıramadığı için kodu sizin bilgisayarınızdaki küçük bir yardımcı program derleyip çalıştırır: C/C++ g++/clang++ ile CPU'da, CUDA nvcc ile GPU'da.

  1. runner.py dosyasını indirin (sadece Python 3 gerekir).
  2. Terminalde: python3 runner.py (Windows: py runner.py). Pencere açık kaldığı sürece düğmeler çalışır.
  3. ✎ Düzenle · parametreler: bloğun tam programını düzenleyin, derleyici bayraklarını (ör. -O3, -arch=sm_86, -gencode …, --ptxas-options=-v) ve program argümanlarını (ör. matris boyutu) yazın.

Çalıştırıcı sadece 127.0.0.1'i dinler ve sadece bu sitenin isteklerini kabul eder. Bilgisayarınızda derleyici yoksa: Google Colab (T4 GPU; %%writefile k.cu ve !nvcc k.cu -o k && ./k) ya da derleme çıktısını (PTX/SASS) görmek için godbolt.org.

#include 
__global__ void who(int width) {
    int col = blockIdx.x * blockDim.x + threadIdx.x;
    int row = blockIdx.y * blockDim.y + threadIdx.y;
    int id  = threadIdx.y * blockDim.x + threadIdx.x;
    if (blockIdx.x == 2 && blockIdx.y == 1 && threadIdx.x == 5 && threadIdx.y == 10)
        printf("row=%d col=%d warp=%d P[%d]\n", row, col, id / 32, row * width + col);
}
int main() {
    who<<>>(24);
    cudaDeviceSynchronize();   // kernel asenkron: çıktıyı görmek için bekle
}
